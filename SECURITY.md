# Security Policy

The canonical security policy lives at
**[`.github/SECURITY.md`](.github/SECURITY.md)** — that copy is what GitHub
surfaces in the repository's **Security** tab.

This root file is kept in sync with it for visibility. Contents:

- [Supported versions](.github/SECURITY.md#supported-versions)
- [Reporting a vulnerability](.github/SECURITY.md#reporting-a-vulnerability)
- [What to expect](.github/SECURITY.md#what-to-expect)
- [Security considerations for this project](.github/SECURITY.md#security-considerations-for-this-project)
- [Vulnerability disclosure](.github/SECURITY.md#vulnerability-disclosure)

**TL;DR:** if you discover a security issue, report it privately via a
[security advisory](https://github.com/itisuniqueofficial-gh/bank-upi-qr-code-generator/security/advisories/new) —
**do not** open a public issue.
